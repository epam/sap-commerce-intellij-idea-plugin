Reports a property that the SAP Commerce Cloud build process writes itself being declared by the project.

SAP states plainly what follows from overriding them: "Modifying these properties may cause your builds to fail." They are reported wherever the declaration lives, local.properties included, because a value that works locally is exactly the one that breaks the cloud build.

Two families are reported:

  • Set by the build process — connector and JMX ports (tomcat.http.port, tomcat.ssl.port, tomcat.ajp.port, proxy.http.port, …), JVM options (tomcat.javaoptions, java.mem, standalone.javaoptions, …), caching (regioncache.entityregion.size, cms.cache.enabled), the authserver.keystore.* settings and the audit.siem.* settings.
  • Editable in the Cloud Portal only — bootstrap.init.type.system.custom.indices.use.items.definitions and bootstrap.init.type.system.custom.index.ignore.names.starting.with, which an update overwrites or removes unless they are edited in the Cloud Portal using the hcs_admin aspect.

See Managed Properties on the SAP Help Portal.
