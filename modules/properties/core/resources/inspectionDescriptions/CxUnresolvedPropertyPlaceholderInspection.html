Reports a ${...} placeholder the platform would never expand.

A property value may refer to another property, and SAP Commerce substitutes it while resolving the chain. When it cannot, it does not fail — it leaves the literal ${...} in the value, which then reaches whatever reads the property. A path with an unexpanded placeholder in it is a directory that does not exist; a URL with one is a host nothing answers on.

Three cases are reported:

  • No property declares this key — a typo, or a property somebody meant to add and did not. The quick fix declares it in local.properties and opens the file so a value can be typed.
  • A reference cycle — the placeholder leads back to the property being declared, directly or through others. The platform detects this and gives up, leaving the placeholder as written.
  • An empty placeholder — ${} names nothing at all.

Only files the property chain is built from are inspected, so a resource bundle or a test fixture which happens to use the same syntax is left alone.
